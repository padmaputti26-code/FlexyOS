# FlexyOS C71 v0.3 — Reference-Matched Launcher

This build is a more concrete Realme C71 implementation based directly on the supplied reference screenshots.

Implemented:
- Four-column home layout
- Google-style search glass pill
- Cool blue/grey ocean-inspired background
- Translucent cyan/white rounded icon tiles
- White icon treatment
- App labels and dock
- Page indicator
- App discovery from installed launchable apps
- Tap-to-launch
- Swipe up for app drawer / swipe down to return
- Long-press for FlexyOS settings
- Transparent edge-to-edge system bars

Important:
- This is still an Android launcher, not a privileged replacement for Realme SystemUI.
- OEM Quick Settings, lock screen internals and protected Settings UI cannot be replaced by a normal APK without supported system-level integration.
- The project is source code; it is not a precompiled APK.
